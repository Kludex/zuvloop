Apple M3 Max, macOS 26.6.2, CPython 3.14.6, libuv 1.51.0
zuvloop 0.0.14.dev3, uvloop 0.22.1, rloop 0.5.0
zuvloop source: b45158cb14d15ef2463d0c65e9293aff1579bff6 (with rloop added to the benchmark harnesses)
uvicorn 0.52.4, aiohttp 3.14.3, httptools 0.8.0, oha 1.14.0

Seven interleaved in-process runs; five interleaved HTTP runs.
HTTP server warmup: 1s per sample; 64 connections.
Uvicorn measurement: 5s per sample; aiohttp server: 4s per sample.
Aiohttp client: 20,000 requests, concurrency 16, after 2,000 warmup requests.
The aiohttp client benchmark keeps its server on stock asyncio.
The scripts below ran sequentially.
