uvicorn 0.52.4, aiohttp 3.14.3, httptools 0.8.0, oha 1.14.0

Seven interleaved in-process runs; five interleaved HTTP runs.
HTTP server warmup: 1s per sample; 64 connections.
Uvicorn measurement: 5s per sample; aiohttp server: 4s per sample.
Aiohttp client: 20,000 requests, concurrency 16, after 2,000 warmup requests.
The aiohttp client benchmark keeps its server on stock asyncio.
The scripts below ran sequentially.
NO_COLOR=true avoids oha rejecting the inherited NO_COLOR=1 value.

This is a shared developer machine with background load, including a busy virtual machine.
A preliminary full pass was noisy (30-75% variation on several workloads), so all three
harnesses were rerun. The complete second pass is reported below. Some variation remains;
small differences do not establish a performance advantage.
The +/- percentages are population standard deviation divided by mean, not confidence intervals.
