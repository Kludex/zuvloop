README benchmark results - 2026-11-16
Azure Standard_E104is_v5 in Sweden Central: an isolated VM size, so no other tenant shares the hardware.
Intel Xeon Platinum 8370C at 2.80 GHz: 2 sockets, 26 cores per socket, 2 threads per core, 104 vCPUs, 2 NUMA nodes, 672 GiB of memory.
Ubuntu 24.04, kernel 7.0.0-1017-azure, transparent huge pages set to madvise.
CPython 3.14.6 with the GIL, libuv 1.53.0
zuvloop 0.0.18.dev47, uvloop 0.22.1, rloop 0.5.0
Zig 0.16.0, ReleaseFast build
zuvloop source: 328c8be4dd87499c5cde7a63a0025ffe1426910a (main)
uvicorn 0.52.4, aiohttp 3.14.3, httptools 0.8.0, oha 1.14.0, uv 0.13.8

Seven interleaved in-process runs; five interleaved HTTP runs.
HTTP server warmup: 1s per sample; 64 connections.
Uvicorn measurement: 5s per sample; aiohttp server: 4s per sample.
Aiohttp client: 20,000 requests, concurrency 16, after 2,000 warmup requests.
The aiohttp client benchmark keeps its server on stock asyncio.
The scripts below ran sequentially, with nothing else running on the VM.
NO_COLOR=true avoids oha rejecting an inherited NO_COLOR=1 value.

One pass is reported. The processes were not pinned to cores or to a NUMA node.
A run on another VM of the same size earlier the same day, against main before #247,
agreed within 3% on every zuvloop row except getaddrinfo, which read 5% higher there.
Small differences do not establish a performance advantage.
The +/- percentages are population standard deviation divided by mean, not confidence intervals.
