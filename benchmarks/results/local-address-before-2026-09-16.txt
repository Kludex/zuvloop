Command:
COLUMNS=180 uv run --group bench pytest benchmarks/test_benchmarks.py -k concurrent_local_address_resolution --codspeed --codspeed-mode=walltime -q

Workload: five concurrent connections to a loopback server, binding localhost.
Model: inject a 20 ms delay into synchronous hostname binding or asynchronous
local-address resolution. At this baseline, asyncio uses the async resolver and
zuvloop uses synchronous binding. Moving zuvloop to the async path is the intended
change being measured, not a reason to invalidate the benchmark.

Counters assert that each run's resolution count equals its completed-connection
count and that exactly one of the two delay boundaries was used. This detects a
bypassed or double-injected delay without requiring a loop to remain blocking.
The counters also work when pytest runs a single unmeasured smoke iteration.

These results model blocking versus overlap under slow DNS, not the operating
system's resolver throughput. Only asyncio and zuvloop are included because the
injected boundaries are Python methods.

Five rounds, one iteration per round. Best round:
